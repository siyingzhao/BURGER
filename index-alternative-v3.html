Drawing as a robotic task

How effectively can VLA models learn diverse behaviors as training data scales? Answering this requires large, varied robot datasets, which remain costly to collect on physical robots. We propose to study this question through drawing.

A robot starts from a blank canvas and follows a language instruction, yet each instruction allows many valid drawings and stroke orders. This makes the data naturally multimodal, while compositions of familiar objects let us test spatial understanding and generalization to new combinations.

Text-to-image models supply the sketches that our pipeline converts into robot demonstrations, while learned visual features let us evaluate the resulting drawings. Together, these make drawing an ideal setting for studying how vision-language-action models learn as demonstrations scale—and where their execution breaks down.

What happens when VLAs deal with multimodal data?

A circle can be drawn clockwise or counterclockwise. We train on 100 demonstrations with the same shape and radius, using both directions in roughly equal proportions (56% clockwise, 44% counterclockwise). Position and starting point also vary. Can a VLA learn these alternatives and execute one consistently?

Language following and compositional generalization

The initial blank canvas does not reveal which object to draw. The instruction specifies the object and, for a composition, its spatial relation to another object. As the drawing develops, the policy uses the changing canvas as visual feedback.

We also ask whether a policy can combine familiar objects in pairs absent from training. The examples below show π0 executing a seen pair and a held-out pair.

Selected learned-policy rollouts in simulation. Both objects in the held-out pair are familiar from training.

The evaluated policies can produce new combinations of familiar objects, while object categories absent from training remain difficult. Composition can also reduce drawing quality, especially when the instruction set includes vertical relations.

How learning changes with data scale

The generation pipeline lets us vary the number of object classes from 10 to 132 and demonstrations per class from 10 to 100. We use this sweep to study how three OpenPI-family models respond to additional data: the flow-matching models π₀ and π₀.₅, and the autoregressive π₀-FAST.

Drawing similarity across numbers of training classes and demonstrations per class. Higher scores indicate greater similarity to the target object class in the learned sketch embedding.

π0 and π0.5 improve more consistently as data scale increases. π0-FAST shows more variable trends. The models differ in how effectively they use additional drawing demonstrations.

The demonstration generator provides a way to vary task diversity and examples per task within one robot setup, supporting further studies of how training data shapes learned behavior.

How drawing quality is measured

We train a projection head on frozen DINOv3 features to score drawings against their target class. In a study of 10 single-object classes, 66 participants ranked five drawings per class. The metric agrees more closely with their judgments than CLIPScore.

Dataset and demonstration generation

BURGER is designed to support studies of language-conditioned robot data. The dataset provides a starting point, and the generation pipeline lets researchers extend the task set and construct new training demonstrations.

The benchmark contains 28,200 simulated demonstrations: 132 single-object tasks and 150 compositional tasks, with 100 demonstrations per task. The compositional set contains 100 horizontal and 50 vertical tasks.

Scope and limitations

BURGER studies line drawing with a rigid tool. It simplifies the contact physics of painting and manipulation. Generated sketches and stroke-order heuristics shape the data distribution.

The evaluated policies can compose known objects, but struggle to draw unseen object categories. Drawing performance does not establish general manipulation ability.
